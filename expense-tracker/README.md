
# 💰 Personal Expense Tracker

A Python-based expense tracking application that uses SQLite
to store income and expense transactions.

## Features
- Add income and expense transactions
- View transaction history
- Calculate total income, expenses, and balance
- Generate monthly financial reports
- Store records persistently using SQLite
- Validate amounts, dates, and transaction types

## Technologies Used
- Python
- SQLite
- SQL
- Git and GitHub

## Requirements
- Python 3.10 or newer
- No third-party Python packages required

## How to Run

1. Clone or download this repository.
2. Open a terminal in the project folder.
3. Run:

   python expense_tracker.py

## Example

If income is 30000 and expenses are 5000:

- Total income: 30000
- Total expenses: 5000
- Balance: 25000
